# Tools

Image/asset processing scripts used during content creation.
These are standalone Java utilities and not part of the Flutter app.

| File | Purpose |
|---|---|
| AnalyzeBoard.java | Analyze lesson board images |
| BuildSceneImages.java | Build composite scene images |
| CleanBackgrounds.java | Remove/clean image backgrounds |
| CleanWordImages.java | Clean word card images |
| CompositeBorg.java | Composite Borg character images |
| ExtractWordImages.java | Extract word images from sheets |
| FindContentFrame.java | Find content frame boundaries |
| FixBetteekh.java | Fix specific asset (Betteekh) |
| FixBorg.java | Fix Borg character assets |
| FixSpecificFrames.java | Fix specific animation frames |
| PatchBackgrounds.java | Patch/fix background images |

# دستور تنفيذ مشروع فصيح الصغار (Faseeh Kids Execution Constitution)

## الغرض (Purpose)
This document is the SINGLE SOURCE OF TRUTH for any AI agent executing this project. No agent may deviate from it.

## القواعد (Rules)
1. Each task has a unique ID (e.g., P0-T001)
2. Tasks MUST be executed in sequential order within each phase
3. A task is NOT complete until its verification criteria pass
4. No task may be skipped
5. If a task fails, the agent must stop and report — not improvise
6. Context for each task is self-contained — no external knowledge needed

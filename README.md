# فصيح الصغار (Faseeh Kids) 🦅🌿

تطبيق تعليمي تفاعلي حديث لتعليم اللغة العربية للأطفال بأسلوب ممتع وشيق يجمع بين اللعب والتعلم المستند إلى أحدث المناهج التربوية والتقنية.

## مميزات التطبيق
- **مسار الواحات التفاعلي (Oasis Learning Path):** تصميم مبهر مستوحى من أفضل التطبيقات العالمية.
- **شخصية الصقر فصيح (Interactive Mascot):** رفيق تعليمي تفاعلي بمؤثرات فيزيائية وحركية ممتعة.
- **أنشطة تفاعلية متنوعة:** (استمع، ارسم، اكتب، تدرب، اختبر).
- **أصوات بشرية عالية النقاء:** تسجيلات صوتية عصبية فائقة الوضوح.
- **لوحة تحكم ولي الأمر:** متابعة دقيقة لنسب الإنجاز ومستوى إتقان الحروف والكلمات.

## المتطلبات والتشغيل
- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0

```bash
flutter pub get
flutter run
```
